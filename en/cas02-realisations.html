01

Process · Design system

A 5-step workflow

Prioritize components based on project managers' roadmap, inventory them, research online documentation, harmonize them for each product's needs, then deploy the component.

02

Management · Rituals

Rituals to track progress and communicate

A set of recurring meetings tracks progress and communicates product revisions and changes to the relevant stakeholders.

03

Management · Tracking file

A request tracking dashboard

To track every request from project owners, a Google Sheet was set up as a task tracker, paired with a weekly newsletter.

04

Communication · Newsletter

A weekly newsletter for project managers

Every week, a newsletter sent via Outlook to each project manager shares upcoming improvements and changes.

It comes with a presentation deck featuring demos and prototypes of each change.

05

Organization · Figma folder

From 27 to 13 source files

To manage multiple workstreams, the folder was organized following the Atomic Design methodology. The number of source files went from 27 to 13.

An inventory document is shared with project stakeholders so they can track each workstream.

06

Organization · Figma files

Files that show where the work stands

To stop the constant fixing, cleaning up and searching, a working method was introduced in the files. It shows project progress through:

  • a table of contents;
  • a work status on every mockup;
  • logic diagrams;
  • a context section at the top of each journey.
07

Design system · Naming

Component names shared with developers

To bring design and development closer, components were named following developers' conventions.

08

Design system · Cross-platform

One design system for web and native apps

The first iterations of the design system only covered web, without native app platforms. Components are now documented for each platform, shown here for desktop web, mobile web and Apple's guidelines.

09

Design system · Page templates

Page templates to work in parallel

To track and integrate changes across projects, page templates let teams share their work and move forward in parallel.

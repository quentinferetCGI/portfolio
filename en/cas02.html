TL;DR

The problem, my decision, the impact.

Problem

12 interdependent features designed with no brand guidelines or design system, in separate files, handed off as PNGs.

Decision

An end-to-end connected design system, from foundations to page templates, and a new file organization.

Impact

Design production dropped from 80% to 20% of the time, and a design system shared across all IDFM products was launched.

Context & challenge

Independent stakeholders, before a design team was in place.

As a designer on the ticketing modernization program (PMB), I worked on the user journeys of 12 interdependent features, alongside several teams each working in their own files, some dating back to 2019.

At IDFM, the project had been launched with several independent stakeholders before a design team came on board. Project managers and stakeholders had started designing mockups without relying on IDFM's brand guidelines, which did not exist at the time, or on the platform conventions of each technology.

Key issues

P1 · PRODUCTION

Production out of sync with the mockups

Mockups had been designed without accounting for the functional specifications of each platform or IDFM's digital brand guidelines.

P2 · FILES

No file organization

Time was spent hunting for mockups and figuring out how screens connected.

P3 · HANDOFF

A painful handoff to developers

Mockups were delivered as PNG files, so developers' inspection tools could not work.

Approach

Four challenges, one end-to-end connected system.

Help structure a cross-platform design system serving multiple features across the Île-de-France Mobilités ecosystem.

  1. Consolidate existing assets

    Identify what can be shared and reused from one feature to the next.

  2. Ensure consistency

    Structure changes around the specifics of web, Android and iOS.

  3. Streamline handoff

    Make functional specifications clear for engineering teams.

  4. Build in accessibility

    Account for RGAA, RAAM and audit findings on features under development.

Key decisions

Four decisions to move from mockups to a system.

Each decision addresses a specific finding and leads to a measurable outcome.

D1

Connect foundations to components

Finding
No design system, and no IDFM digital brand guidelines when the project started.
Decision
Translate the brand guidelines into foundations, create the iOS and Android libraries, refactor production components, and build the molecule and page levels.
Impact
+2 levelsan end-to-end connected system, from foundations to page templates.
D2

Reorganize the file structure

Finding
No organization: time was lost looking for mockups.
Decision
A new folder structure built around key files to document, test, share and build.
Impact
Fewer filesdesign effort is synchronized across all features to be delivered.
D3

Hand off a format developers can use

Finding
Mockups delivered as PNGs: inspection tools did not work.
Decision
Improve deliverables and handoff information for faithful implementation, with components analyzed by state and variant.
Impact
0 → 30%of time spent on handoff.
D4

Drive adoption of new methods by showing, not telling

Finding
Varied design profiles spread across multiple teams.
Decision
Tailored coaching for each person, plus demos and interactive prototypes for management, with active listening to their needs.
Impact
Cross-team projecta design system shared across all IDFM-branded products was launched.

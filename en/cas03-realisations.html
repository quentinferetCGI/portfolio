Documentation · Accessibility

Documentation with RGAA built in

Example of the icon-only button: its states (default, hover, focus) and sizes, keyboard interactions, the HTML elements, roles and attributes to use, and the RGAA accessibility criteria to check.

02

User research · Design sprint

A co-creation workshop for Télérecours for citizens

On March 16, 2023, a design sprint brought together the project's stakeholders. In five steps: imagine a proto-persona, map their journey and pain points, prioritize them, vote on ideas, then define next steps.

The selected ideas were prototyped and integrated into the mockups of version 2 of Télérecours for citizens.

03

Handoff · Ready to Dev

A handoff file organized by user story

The Ready to Dev file was reworked for developers:

  • pages organized by sprint, then by user story;
  • an information sheet at the top of each user story: design lead, accessibility lead, last update date and user story;
  • the mockup, its technical specifications and annotated interactions.
